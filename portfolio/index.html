SYNC-01 State and concurrency

Preserving unsent work across revisions

A repair treated a newly observed server revision as the basis of an unsent draft. A test required that faulty form. A sequence through checkpoint and reload exposed the overwrite.

The check that matters

Edit locally, edit remotely, pull, checkpoint, reload and save. Inspect the server's document and accepted writes. A single-device smoke check still passes in the faulty variants.

Correction

Keep the draft's basis revision until an accepted save or explicit conflict resolution. The planted regression corrupts only the durable checkpoint, requiring reload to expose it.

Historical context and limits

A private review of August 2026 code history records the defect, agent review counterexample and subsequent sequence checks. Historical browser and physical two-device acceptance were not established. This example uses a synthetic state machine and in-memory persistence.

Read the case and acceptance code ↗

A passing smoke control covers only one device. The acceptance sequence checks competing edits and reload.

DATA-01 Data integrity and boundaries

Reading back every promised upload copy

A development upload returned success while one storage destination held no original. A serialized batch boundary was missed. Independent byte readbacks contradicted the completeness claim.

The check that matters

Measure the modeled JSON request size, then read every original independently and compare its length and SHA-256. A write acknowledgement alone cannot establish a complete copy.

Correction

Write bounded parts separately and report complete, degraded, unconfirmed or unavailable storage. The planted regression retains bounded writes but trusts acknowledgements when a readback is truncated.

Historical context and limits

The private October 2026 review records roughly 9.5 MB and 20.65 MB originals read back across three development stores after repair. This public model uses deterministic non-image bytes and a modeled 32 MiB JSON envelope. It does not reproduce the full provider protocol or test mail, real stores or production.

Read the case and acceptance code ↗

Fixture bytes are synthetic. Exact modeled envelope sizes are not historical provider measurements.

OPS-01 Orchestration and recovery

Bounding retries when discovery fails

An independent review reproduced eight drains opening eight sessions while separate upload and alert tests were green. Another restart path lost the opened session's identity.

The check that matters

Count the fake launcher's sessions over repeated drains, unknown inventory and worker restart. Inspect the durable queue and recipient inbox separately from launch acceptance.

Correction

Bound launches, retain undelivered work, distinguish unknown inventory, preserve the target across restart and make uncertain launches explicit. The planted regression treats unknown inventory as empty.

Historical context and limits

The October 2026 review verified a corrected candidate in isolation. This reconstruction uses a virtual clock, fake sessions and in-memory queue state. It neither starts real agents nor establishes exactly-once delivery, current activation or the cause of the historical computer freeze.

Read the case and acceptance code ↗

All launches are fake. An uncertain acknowledgement stays unresolved rather than being called delivered.

02 / Verification method

A check supports the claim it measures.

01

Refute the faulty behavior

The same assertions run against each variant. A named counterexample must fail; an unrelated setup error cannot stand in for evidence.

02

Observe the stored outcome

Read the server document, stored bytes or queue state. Keep response labels and underlying outcomes separate.

03

Bind results to source

Receipts record exact executable fingerprints, runtime, command, outcomes and artifact hashes. Empty, skipped and interrupted runs are rejected.

03 / Contribution

KJR — requirements and QA direction

KJR owns Roots of Reason, challenged unsupported completion claims and required stronger verification, consumer tracing and visible failures. Agents implemented historical repairs and supplied several specific counterexamples and independent reviews. The models, tests and public packet here were prepared with Codex under KJR's direction.

The private record does not establish sole human authorship of every mechanism. The per-case notes preserve those distinctions. Raw transcripts, family records and live access details remain private.
