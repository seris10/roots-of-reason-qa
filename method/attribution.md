# Contribution and attribution

KJR directed the QA requirements and review standards for Roots of Reason. Private direct user records support demands that smoke-test conclusions stay within their assertions, verification methods reach the responsible agents, changed consumers be traced, failures remain visible, and repairs preserve functionality. Those requirements are distinct from inventing or implementing every technical mechanism.

| Case | KJR contribution supported by the record | Historical agent contribution | Public reconstruction |
|---|---|---|---|
| SYNC-01 | Broader direction that QA claims match actual checks; the particular repair's human origin is not established | Developer-agent repair; independent agent reviewer identified a sequence counterexample and challenged a test that required faulty behavior | Newly written model and tests prepared with Codex |
| DATA-01 | Required redundant saving, independent verification and visible reporting for success and failure | Agents built the copy paths; an independent agent reviewer found the large-batch boundary through readback and checked the correction | Newly written bounded-envelope model and independent hash assertions prepared with Codex |
| OPS-01 | Required loud failure reporting, reliability and bounded resource use | An agent candidate introduced an unbounded retry path; independent agent review reproduced it and checked the bounded candidate | Newly written fake launcher, restart model and virtual-clock tests prepared with Codex |

Historical observations are described as documented private evidence, not as public original test runs. Dates and outcomes in the case summaries come from the private audit; the public receipts describe only the new synthetic runs.

The public packet does not claim KJR manually wrote all code, originated each specific test, independently performed every historical verification or accepted every proposed repair. No attribution is inferred from a commit's configured author alone.

The original raw transcripts and source references remain private because they contain family context and internal paths. The private audit preserves message roles, timestamps, source fingerprints and uncertainty; the public edition preserves the technical mechanism and contribution boundaries without exporting that material.
